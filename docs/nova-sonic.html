⚠️ 為什麼不能直接在靜態頁面呼叫？

問題說明
AWS SigV4 簽署靜態前端無法安全地簽署 AWS 請求（需要 Secret Key）
雙向串流Nova Sonic 使用 InvokeModelWithBidirectionalStream，不是一般 HTTP POST
CORSBedrock Runtime 不支援瀏覽器直接跨域呼叫
帳號權限本 Workshop 帳號無法建立 API Gateway 或 Lambda Function URL

📝 Python 實作範例（完整可執行）

在有完整 AWS 權限的環境中，用以下程式碼呼叫 Nova Sonic：

import boto3
import json
import asyncio

# Nova Sonic 需要使用 bedrock-runtime 的雙向串流
client = boto3.client('bedrock-runtime', region_name='us-west-2')

async def nova_sonic_conversation(audio_bytes: bytes) -> dict:
    """
    使用 Nova Sonic 進行語音對話
    Input: PCM 16-bit, 16kHz, mono audio
    Output: Speech audio + transcribed text
    """

    # Nova Sonic 使用 InvokeModelWithBidirectionalStream
    # 這是一個 WebSocket-like 的雙向串流 API
    response = client.invoke_model_with_bidirectional_stream(
        modelId='amazon.nova-2-sonic-v1:0',
        body=json.dumps({
            "inputAudio": {
                "audioConfig": {
                    "sampleRateHertz": 16000,
                    "encoding": "PCM",
                    "channelCount": 1
                },
                "audioData": audio_bytes.hex()  # PCM audio as hex
            },
            "inferenceConfig": {
                "maxTokens": 1024,
                "temperature": 0.7
            },
            "systemPrompt": "You are a helpful voice assistant. Respond naturally."
        })
    )

    # 處理串流回應
    results = {"text": "", "audio_chunks": []}
    for event in response['body']:
        chunk = json.loads(event['chunk']['bytes'])
        if 'textOutput' in chunk:
            results['text'] += chunk['textOutput']
        if 'audioOutput' in chunk:
            results['audio_chunks'].append(
                bytes.fromhex(chunk['audioOutput'])
            )

    return results


# 使用範例
if __name__ == '__main__':
    # 讀取音訊檔案 (PCM 16-bit, 16kHz, mono)
    with open('input.pcm', 'rb') as f:
        audio = f.read()

    result = asyncio.run(nova_sonic_conversation(audio))
    print(f"Transcription: {result['text']}")
    print(f"Audio chunks: {len(result['audio_chunks'])}")

    # 儲存回應音訊
    with open('output.pcm', 'wb') as f:
        for chunk in result['audio_chunks']:
            f.write(chunk)

🚀 如何在自己的環境部署

要做一個完整的 Nova Sonic Web 應用，你需要：

# 1. 建立 Lambda + API Gateway WebSocket
#    （本 Workshop 帳號權限不足，需要自己的 AWS 帳號）

# 2. 前端：錄音 → 送到 WebSocket → 播放回應音訊
#    使用 MediaRecorder API + Web Audio API

# 3. 後端 Lambda：
#    接收 audio chunks → 呼叫 Nova Sonic → 回傳 audio

# 快速開始（需要 SAM CLI）：
sam init --name nova-sonic-app --runtime python3.12
# 修改 template.yaml 加入 WebSocket API Gateway
# 部署：sam deploy --guided
